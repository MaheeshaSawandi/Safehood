## 📌 Overview

**Safehood** is a smart personal safety and emergency assistance mobile application designed to help users improve their security and respond effectively during emergency situations.

The application provides users with quick access to emergency services, safety alerts, crime reporting facilities, safe zone information, and personalized security features. Safehood aims to create a safer environment by connecting users with important safety resources through a single platform.

# 🚀 Getting Started

## Prerequisites

Before running the project, make sure you have:

- Flutter SDK installed
- Dart SDK installed
- Android Studio / VS Code
- Android Emulator or Physical Device

## Installation

### Clone the repository

```bash
git clone https://github.com/MaheeshaSawandi/Safehood.git
Navigate to project directory

Install dependencies
flutter pub get
